# 🌟 Not Stars Web App

**Not Stars Bot** — это мини-игра во вселенной Telegram,  
где ты собираешь звёзды, активируешь «⭐ Звёздную лихорадку»  
и прокачиваешь свой счёт прямо в Web App!

---

## 🚀 О проекте

- 🤖 Telegram-бот: [@NotStars_kkbot](https://t.me/NotStars_kkbot)  
- 💻 Web App написан на **HTML / CSS / JavaScript**  
- ⚡ Работает прямо внутри Telegram через встроенную кнопку «Открыть игру»  
- 🎯 Без серверной части — всё происходит на клиенте  

---

## 🎮 Возможности

- 🖱 Кликер для сбора звёзд  
- 🔥 «Звёздная лихорадка» — бонус с таймером  
- 💾 Сохранение счёта и состояния  
- 📱 Удобный дизайн под мобильные устройства
